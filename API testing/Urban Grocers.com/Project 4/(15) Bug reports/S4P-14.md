## 📝 Description
The API returns incorrect delivery availability when the `deliveryTime` parameter is missing.  
The system should not make the “Fast Delivery” service available if `deliveryTime` is empty.  
However, the response still marks it as available (`isItPossibleToDeliver="true"`) instead of `"false"`.

### **Precondition:**  
- Endpoint: `/fast-delivery/v3.1.1/calculate-delivery.xml`  
- API client such as Postman.

---

### **Steps to Reproduce:**
1. Send `POST /fast-delivery/v3.1.1/calculate-delivery.xml`.  
2. Body with **missing `deliveryTime`**:
   ```xml
   <InputModel>
       <productsCount>11</productsCount>
       <productsWeight>4.5</productsWeight>
       <deliveryTime></deliveryTime>
   </InputModel>

### **Expected Result:**  
```xml
name="Fast Delivery"
isItPossibleToDeliver="false"
hostDeliveryCost="6"
clientDeliveryCost="0"
<toBeDeliveredTime>
   <min>25</min>
   <max>30</max>
</toBeDeliveredTime>


```

### **Actual Result:**  
```xml
name="Fast Delivery"
isItPossibleToDeliver="true"
hostDeliveryCost="6"
clientDeliveryCost="0"
<toBeDeliveredTime>
   <min>25</min>
   <max>30</max>
</toBeDeliveredTime>

```
