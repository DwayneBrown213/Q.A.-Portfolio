## 📝 Description
When adding products to a kit, if the **kitId** parameter in the endpoint is missing (blank), the API returns **405 Method Not Allowed** instead of **404 Not Found** for invalid endpoints.

### **Precondition:**  
- Existing product ID available (e.g., `id: 7`).

### **Steps to Reproduce:**
1. Send `POST /api/v1/kits/products`.  
2. Body:
   ```json
   {
     "productsList": [
       { "id": 7, "quantity": 1 }
     ]
   }

### **Expected Result:**  
404 Not Found
### **Actual Result:**  
405 Method Not Allowed

**OS:** *Windows 10 Home 22H2*<br>
