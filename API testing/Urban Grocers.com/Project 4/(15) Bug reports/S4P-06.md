## 📝 Description
When adding products to a valid kit with fewer than 30 products, the API fails to properly validate the `productID` parameter.  
If Latin letters are entered instead of a numeric value, the server returns **500 Internal Server Error** instead of the expected **400 Bad Request**.  
After this error occurs, the API becomes unresponsive to further product additions to the affected kit ID.

### **Precondition:**  
- Valid kit exists (e.g., `/api/v1/kits/6`).
- Kit currently contains fewer than 30 products.

### **Steps to Reproduce:**
1. Send `POST /api/v1/kits/6/products`.  
2. Use **Latin letters** for `productID`:
   ```json
   { 
     "productsList": [ 
       { "id": "LATI", "quantity": 1 } 
     ] 
   }

### **Expected Result:**  
400 Bad Request
### **Actual Result:**  
500 Internal Server Error
