## 📝 Description
The API returns incorrect delivery details when the `productsWeight` parameter exceeds requirements.  
The `hostDeliveryCost="7"` & `clientDeliveryCost="9"` should return when `productsWeight` input is over the limit.  
Instead, the system returns mismatched cost data.

### **Precondition:**  
- Endpoint: `/fast-delivery/v3.1.1/calculate-delivery.xml`  
- API client such as Postman.

### **Steps to Reproduce:**
1. Send `POST /fast-delivery/v3.1.1/calculate-delivery.xml`.  
2. Body with **invalid `productsWeight`**:
   ```xml
   <InputModel>
       <productsCount>4</productsCount>
       <productsWeight>7</productsWeight>
       <deliveryTime>9</deliveryTime>
   </InputModel>

### **Expected Result:**  
```xml
name="Fast Delivery"
isItPossibleToDeliver="true"
hostDeliveryCost="7"
clientDeliveryCost="9"
<toBeDeliveredTime>
   <min>25</min>
   <max>30</max>
</toBeDeliveredTime>
```

### **Actual Result:**  
```xml
name="Fast Delivery"
isItPossibleToDeliver="true"
hostDeliveryCost="6"
clientDeliveryCost="6"
<toBeDeliveredTime>
   <min>25</min>
   <max>30</max>
</toBeDeliveredTime>
```
