## 📝 Description
When adding products to a kit, if the **kitId** in the endpoint contains **Latin letters** instead of a valid numeric ID, the API crashes with **500 Internal Server Error** instead of returning **404 Not Found** for invalid endpoints.

### **Precondition:**  
- Existing product ID available (e.g., `id: 6`).

### **Steps to Reproduce:**
1. Send `POST /api/v1/kits/LA/products`.  
2. Body:
   ```json
   {
     "productsList": [
       { "id": 6, "quantity": 1 }
     ]
   }

### **Expected Result:**  
400 Bad Request
### **Actual Result:**  
500 Internal Server Error.

**OS:** *Windows 10 Home 22H2*<br>
**Browsers:** 
*Chrome Version 133.0*<br>
