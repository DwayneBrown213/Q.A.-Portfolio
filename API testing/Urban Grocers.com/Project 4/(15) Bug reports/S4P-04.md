## 📝 Description
When attempting to add an existing product to a blank kit ID using the `/api/v1/kits/:id/products` endpoint (without providing a valid kit ID in the URL), the API returns **405 Method Not Allowed** instead of **404 Not Found**.  
The invalid endpoint should result in a "Not Found" response, not a "Method Not Allowed" error.

### **Precondition:**  
- Existing product with a valid product ID (e.g., `id: 7`).
- Valid `quantity` parameter (e.g., `quantity: 1`).

### **Steps to Reproduce:**
1. Send `POST` request to endpoint without specifying kit ID:  
    `**POST** /api/v1/kits/products`
2. Body with **valid parameters**:
    ```json
    {
      "productsList": [
        {
          "id": 7,
        "quantity": 1
        }]}



### **Expected Result:**  
`404 Not Found` should be returned because the endpoint /api/v1/kits/:id/products requires a valid kitId.
### **Actual Result:**  
`405 Method Not Allowed` is returned.
