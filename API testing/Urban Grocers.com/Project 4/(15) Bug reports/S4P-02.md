## 📝 Description
When adding existing products to a kit, if the request body omits the `quantity` key for a product item, the API responds with **500 Internal Server Error**.  
It should validate the payload and return **400 Bad Request** with an explanatory error message (e.g., “quantity is required”).

### **Precondition:**
- A valid kit exists (e.g., `kitId = 4`).
- A valid product exists (e.g., `id = 4`).

### **Steps to Reproduce:**
1. Send a `POST` request to:  
   `URL + /api/v1/kits/4/products`
2. Use the following body (note the missing `quantity` key):
   ```json
    {
     "productsList": [
       { "id": 4 }]}

### **Expected Result:** 
400 Bad Request 
### **Actual Result:**
500 Internal Server Error.
