## 📝 Description
The API incorrectly marks the “Fast Delivery” service as available when the `deliveryTime` parameter contains Latin letters.  
The system should reject the request or return `isItPossibleToDeliver="false"` when the parameter is not a valid numeric value.  
However, the API returns a successful response with `isItPossibleToDeliver="true"`, causing invalid data to pass validation.

### **Precondition:**  
- Endpoint: `/fast-delivery/v3.1.1/calculate-delivery.xml`  
- API client such as Postman.

---

### **Steps to Reproduce:**
1. Send `POST /fast-delivery/v3.1.1/calculate-delivery.xml`.  
2. Body with **invalid `deliveryTime` (Latin letter)**:
   ```xml
   <InputModel>
       <productsCount>12</productsCount>
       <productsWeight>5</productsWeight>
       <deliveryTime>c</deliveryTime>
   </InputModel>

### **Expected Result:**  
```xml
name="Fast Delivery"
isItPossibleToDeliver="false"
hostDeliveryCost="6"
clientDeliveryCost="0"
<toBeDeliveredTime>
   <min>25</min>
   <max>30</max>
</toBeDeliveredTime>
```

### **Actual Result:**  
```xml
name="Fast Delivery"
isItPossibleToDeliver="false"
hostDeliveryCost="6"
clientDeliveryCost="0"
<toBeDeliveredTime>
   <min>25</min>
   <max>30</max>
</toBeDeliveredTime>
```
