## 📝 Description
When attempting to add multiple products to a kit that already contains more than 30 products, the API incorrectly accepts the request and returns **200 OK** instead of validating the request and returning **400 Bad Request**.

### **Precondition:**  
- Valid kit exists (e.g., `/api/v1/kits/5`).
- Kit already contains more than 30 products.

### **Steps to Reproduce:**
1. Send `POST /api/v1/kits/5/products`.  
2. Body with **multiple existing product IDs** and **invalid quantities**:
   ```json
   {
     "productsList": [
       { "id": 10, "quantity": 15 },
       { "id": 11, "quantity": 1 }
     ]
   }
### **Expected Result:**  
400 Bad Request
### **Actual Result:**  
200 OK — API accepts excessive products for existing Kit IDs.
