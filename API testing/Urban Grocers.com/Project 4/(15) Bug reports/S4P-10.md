## 📝 Description
The API allows adding products to a kit without requiring any data in the request body. When an empty JSON object `{}` is sent, it incorrectly returns **200 OK** instead of validating the input and returning **400 Bad Request**.

### **Precondition:**  
- Valid kit exists (e.g., `/api/v1/kits/2`).

### **Steps to Reproduce:**
1. Send `POST /api/v1/kits/2/products`.  
2. Body with **no product data**:
   ```json
   { }
   
### **Expected Result:**  
400 Bad Request
### **Actual Result:**  
200 OK — The API accepts the request with no data.
