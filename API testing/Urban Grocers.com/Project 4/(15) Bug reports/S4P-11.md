## 📝 Description
The **Fast Delivery** API endpoint returns incomplete response data when invalid parameters for product count, product weight, and delivery time are sent. Instead of returning the expected full response indicating that delivery is not possible, the API omits required fields.

### **Precondition:**  
- Fast Delivery service endpoint available: `/fast-delivery/v3.1.1/calculate-delivery.xml`

### **Steps to Reproduce:**
1. Send `POST /fast-delivery/v3.1.1/calculate-delivery.xml`.  
2. Body with **invalid parameters**:
   ```xml
   <InputModel>
       <productsCount>16</productsCount>
       <productsWeight>6.5</productsWeight> 
       <deliveryTime>5</deliveryTime>
   </InputModel>
   
### **Expected Result:**  
  Response should include:
  ```xml
  <name>Fast Delivery</name>
    <isItPossibleToDeliver>FALSE</isItPossibleToDeliver>
    <hostDeliveryCost>7</hostDeliveryCost>
    <clientDeliveryCost>9</clientDeliveryCost>
    <toBeDeliveredTime>
      <min>25</min>
      <max>30</max>
    </toBeDeliveredTime>
```

### **Actual Result:**  
200 OK

Response only includes
  ```xml
  <name>Fast Delivery</name>
```
