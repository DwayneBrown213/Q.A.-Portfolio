## 📝 Description
When adding products to a kit with fewer than 30 items, the API incorrectly accepts requests missing the **product ID key-value pair** in the request body. The system returns **200 OK** and adds the product, instead of validating the input and returning **400 Bad Request**.

### **Precondition:**  
- Valid kit exists (e.g., `/api/v1/kits/3`).
- Kit currently contains fewer than 30 products.

### **Steps to Reproduce:**
1. Send `POST /api/v1/kits/3/products`.  
2. Body **missing product ID**:
   ```json
   { 
     "productsList": [  
       { "quantity": 1 }  
     ]  
   }


### **Expected Result:**  
400 Bad Request
### **Actual Result:**  
200 OK — request passes even though product ID key-value pair is missing.
