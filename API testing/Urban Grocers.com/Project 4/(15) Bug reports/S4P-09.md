## 📝 Description
When attempting to add multiple products to a kit, the API does not validate the `productsList` parameter. If an empty array is sent, the system incorrectly returns **200 OK** instead of **400 Bad Request**, allowing an invalid request to be accepted.

### **Precondition:**  
- Valid kit exists (e.g., `/api/v1/kits/2`).

### **Steps to Reproduce:**
1. Send `POST /api/v1/kits/2/products`.  
2. Body with **empty `productsList`**:
   ```json
   {
     "productsList": [ ]
   }

### **Expected Result:**  
400 Bad Request — request should fail due to missing product data.
### **Actual Result:**  
200 OK — API accepts request even though no product data is provided.
