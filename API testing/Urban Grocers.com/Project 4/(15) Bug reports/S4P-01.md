## 📝 Description
When adding products to a kit, if quantity contains letters, symbols or is missing, the API crashes with **500 Internal Server Error** instead of validating input and returning **400 Bad Request**.

### **Precondition:**  
- Valid kit exists (e.g., `/api/v1/kits/3`).
 
### **Steps to Reproduce:**
1. Send `POST /api/v1/kits/3/products`.  
2. Body with **letters**:
   ```json
   { "productsList": [ { "id": 3, "quantity": "LATI" } ] }



### **Expected Result:**  
400 Bad Request
### **Actual Result:**  
500 Internal Server Error.
