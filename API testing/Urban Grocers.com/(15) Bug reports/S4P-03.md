## 📝 Description
When adding existing products to a kit, if the endpoint contains **Latin letters** instead of a valid numeric `kitId`, the system responds with **500 Internal Server Error** instead of returning **404 Not Found** as expected for an invalid endpoint.

### **Precondition:**  
- The product with `id` 6 exists in the database.  
- Valid `quantity` parameter is used.

### **Steps to Reproduce:**
1. Send `POST /api/v1/kits/LA/products`.  
2. Body with valid product and quantity:
   ```json
   {
     "productsList": [
       { "id": 6, "quantity": 1 }
     ]
   }

### **Expected Result:**  
400 Bad Request
### **Actual Result:**  
500 Internal Server Error.

**OS:** *Windows 10 Home 22H2*<br>
