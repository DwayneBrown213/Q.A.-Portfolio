## 📝 Description
On Order Tracking, the cost is shown as a single total for all restaurants. Requirement calls for per-restaurant costs on the map.

### **Precondition:**  
- Order contains dishes from **multiple restaurants**.  
- User is on **Order Tracking** screen.
  
### **Steps to Reproduce:**
1. Select a pick-up point.  
2. Add dishes from 2+ restaurants.  
3. Confirm the order and open **Order Tracking**.  
4. Observe cost display on the map.



### **Expected Result:**  
Map shows the **cost of all dishes ordered at each restaurant**
### **Actual Result:**  
**One combined total** is displayed instead of **per-restaurant costs**.
