## 📝 Description
On the “Dish selection” screen, tapping **“+”** does add the dish to the order list, but the **"Next" button in the footer** stays the same grey color with no success/active indication.
### **Precondition:**  
- Pick-up point selected.  
- User is on **Dish selection** screen.

### **Steps to Reproduce:**
1. Open the Dish selection screen.  
2. Tap **“+”** on any dish.  
3. Observe the **“Next”** button in the footer and visual feedback.



### **Expected Result:**  
Tapping **“+”** **adds the dish to the order list** (nearest restaurant to the pick-up point). UI should provide clear feedback that the item was added.
### **Actual Result:**  
Dish is added, but **no visible state change**; "Next" button remains grey—unclear to user that the action succeeded.
