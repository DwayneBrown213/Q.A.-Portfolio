## 📝 Description

### **Precondition:**  
 Map screen is open; Landscape mode button visible.
 
### **Steps to Reproduce:**
Bring the cursor close to the Landscape mode button.
   
### **Expected Result:**  
The button changed color. The map button color is light grey.

### **Actual Result:**  
There is no "Landscape" button, instead there is the "Terrain" Checkbox. When the cursor hovers over the Terrain checkbox, it becomes light gray, and the "Map" button returns to white.
