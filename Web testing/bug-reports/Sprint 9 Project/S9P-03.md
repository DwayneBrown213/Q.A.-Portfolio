## 📝 Description

### **Precondition:**  
 In the web browser the "About Customer” form is displayed and blank.
 
### **Steps to Reproduce:**
1. Enter the application’s web address in the browser.
2. Accept cookies.
3. Click the order button.
4. Leave field blank and click the “Next” button at the bottom of the screen.


### **Expected Result:**  
The error message highlighted in red *"Enter correct name"* should be displayed.
### **Actual Result:**  
An error message: *"Enter a valid name"* is displayed

**OS:** *Windows 10 Home 22H2*<br>
