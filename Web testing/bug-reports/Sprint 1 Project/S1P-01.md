## 📝 Description

### **Precondition:**  
 Map screen is open; “From” input is visible.
 
### **Steps to Reproduce:**
1. Enter the application’s web address in the browser.
2. Click the “From” field.

### **Expected Result:**  
The "From" field is selected. The cursor is blinking. The search field is empty.
### **Actual Result:**  
The “From” field is not empty; after clicking, a gray inactive address appears.
