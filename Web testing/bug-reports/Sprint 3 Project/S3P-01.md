## 📝 Description
When the Aero Taxi icon is selected after overriding the server response and providing valid addresses, the app shows a white screen and freezes instead of calculating time and cost.

### **Precondition:**  
-Aero Taxi feature enabled.

-“To” and “From” addresses are entered.

-“Aero Taxi Icon” appears.
 
### **Steps to Reproduce:**
1. Enable the *Aero Taxi* feature.  
2. In DevTools → **Network** panel, search for the relevant request type.  
3. Right-click the JSON file → **Override content** → paste the new JSON over the existing one → **Ctrl+S** to save.  
4. Reload the page.  
5. Enter valid addresses into the **From** and **To** fields.  
6. Click the **Custom** button.  
7. Click the helicopter **“Aero Taxi Icon.”**


### **Expected Result:**  
The total travel **time** and **cost** are calculated correctly.
### **Actual Result:**  
After selecting the helicopter **“Aero Taxi Icon,”** a **white screen** appears and the system **freezes**. No calculation is displayed.
