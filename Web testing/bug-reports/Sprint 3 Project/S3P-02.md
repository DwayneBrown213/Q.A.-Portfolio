## 📝 Description
Negative testing of the *Aero Taxi* flow. After overriding the server response and triggering the *Aero Taxi* calculation, the UI fails to display the total time and cost. The app turns white and becomes unresponsive.

### **Precondition:**  
- Aero Taxi feature enabled.

- “To” and “From” addresses are entered.

- “Aero Taxi Icon” appears.
 
### **Steps to Reproduce:**
1. Enable the *Aero Taxi* feature.  
2. In DevTools → **Network** panel, search for the relevant request type.  
3. Right-click the JSON file → **Override content** → paste the new JSON over the existing one → **Ctrl+S** to save.  
4. Reload the page.  
5. Enter valid addresses into the **From** and **To** fields.  
6. Click the **Custom** button.  
7. Click the helicopter **“Aero Taxi Icon.”**


### **Expected Result:**  
The **calculation result** should display the **total travel time** and **cost** for *Aero Taxi*.
### **Actual Result:**  
After selecting the **“Aero Taxi Icon,”** a **white screen** appears and the system **freezes**. No result is shown.
